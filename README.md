# 📝 ToDoList com Flask

Este é um projeto de uma aplicação web de lista de tarefas (ToDoList) desenvolvida em **Python** utilizando o framework **Flask**. O objetivo é oferecer um ambiente simples, funcional e seguro para que cada usuário possa organizar suas tarefas do dia a dia.

---

## 🚀 Funcionalidades

- Cadastro e login de usuários (com autenticação segura)
- Cada usuário possui seu próprio painel de tarefas
- Criar novas tarefas
- Editar tarefas existentes
- Excluir tarefas
- Marcar tarefas como concluídas
- Interface limpa e intuitiva

---

## 💻 Tecnologias Utilizadas

- Python3
- Flask
- SQLite 
- HTML5 + CSS3 (para a interface)
- JavaScript
